# nysc-deployment-pattern-nigeria
A data analysis project exploring NYSC deployment patterns across Nigeria from 2012 to 2021, using statistical analysis and data visualization to identify state-level distribution trends and deployment patterns.
# NYSC Deployment Pattern in Nigeria (2012–2021)

## Project Overview
This capstone project examines NYSC deployment patterns across Nigeria from 2012 to 2021.

## Dataset Summary
- 19,278 corps members
- 37 state-level deployment areas, including the FCT
- Period covered: 2012–2021

## Key Finding
The five states with the highest deployment numbers accounted for approximately 39% of total deployments.

## Dashboard
The project dashboard is provided in screenshot format.

## Analysis Areas
- Deployment distribution by state
- Geographical deployment patterns
- Deployment distribution by gender

## Tools used
Ms excel, Power BI.
